# User stories: Focus Board

- US1 (F1): As a user I add a task by typing a title and pressing Enter, so capturing work takes seconds.
- US2 (F1): I mark a task done and can undo it, so mistakes are cheap.
- US3 (F1): I edit a task's title and priority, so lists stay accurate.
- US4 (F1): I delete a task and can undo within a few seconds, so I never lose work by accident.
- US5 (F2): I pin tasks to Today and see "3 of 5 done", so I know where I stand.
- US6 (F3): I filter by status and search by text, so I can find things in a long list.
- US7 (F4): I add habits and check them off each day, so I build streaks.
- US8 (F4): I see current and best streak and the last 7 days per habit, so progress is visible.
- US9 (F5): I reload the page and everything is still there.
- US10 (F6): I export my data and import it later or on another device.
- US11 (F6): If I import a broken or malicious file, nothing is overwritten and I get a clear error.
- US12 (F7): I can erase everything after a confirmation.
- US13 (F8, F9): I use the whole app with a keyboard and a screen reader.
- US14 (F10): I use it comfortably on my phone.
