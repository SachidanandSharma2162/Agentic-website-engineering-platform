# User stories: Studio Slot

- US1 (F1): As a visitor I see this week's classes with spots left, so I can choose quickly.
- US2 (F1): I see times in the studio's timezone and in my own, so I do not turn up at the wrong hour.
- US3 (F2): I book a spot with my name and email, so my place is reserved.
- US4 (F2): If the class fills up while I am booking, I get a clear message and the schedule refreshes.
- US5 (F3): I cancel with my code, so someone else can take my spot.
- US6 (F4): I add my booking to my calendar with one tap.
- US7 (F5): As the owner I sign in, add a class and see who has booked.
- US8 (F5): I cancel a class so visitors see it as cancelled.
- US9 (F6): The site stays usable when someone spams it.
- US10 (F7): I use all of it with a keyboard, a screen reader and a phone.
